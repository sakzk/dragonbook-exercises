# p92 2.6.1(1)
字句解析器に､ // で行コメントを無視する処理を追加する｡

```java
int x = 10; // x は 10 です｡
```
方針1:
行コメントの内容を値にもつリテラル
COMMENT タグ

方針2:
完全に無視しちゃう
-> 後続処理(パースなど)でのエラーを報告したいときに､トークンが存在しないと指示できない
-> 行コメントでも､ブロックコメントでもメッセージ出したい時があるはず｡

方針1でいく
1) [x] Comment クラスを作る
  wordをコピペ
    wordの子クラスにはしない
    トークン始まりの､ `//` はlexeme に含める!
      わざわざ取り除くとのトークン字数カウントがめんどくさくなりそう
2) Comment クラスを切り出す処理を､lexer二追加する
  // がトークン開始
  \n がトークン終了
