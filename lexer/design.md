方針1:

方針2:

-> 行コメントでも､ブロックコメントでもメッセージ出したい時があるはず｡

方針1でいく
1) [x] Comment クラスを作る

  \n がトークン終了

- 空白類文字の直後

行コメントの使用例
`// this is coment 123`
`int v = 100; // 100円`
失敗行コメント
`/ this is comment 123`
`int v = 100; / 100円`
-> / は1文字トークンで割り算の記号でも使われる｡
